# Contributing to AbsenzFlow

Vielen Dank für dein Interesse an AbsenzFlow!

## Repositories

AbsenzFlow wird auf mehreren Plattformen gehostet:

- **Lokales GitLab** (nur für Schüler & Lehrkräfte der HHS Karlsruhe)
- **GitHub**: [github.com/digitale-Schulverwaltung-BW/absenzflow](https://github.com/digitale-Schulverwaltung-BW/absenzflow)
- **Codeberg**: [codeberg.org/digitale-Schulverwaltung-BW/absenzflow](https://codeberg.org/digitale-Schulverwaltung-BW/absenzflow)

Externe Beiträge sind über GitHub und Codeberg willkommen, Beiträge aus der HHS natürlich gerne über unser gitlab.

## Wie kann ich beitragen?

### Bug Reports

Wenn du einen Fehler findest:
1. Prüfe ob der Fehler bereits als Issue gemeldet wurde
2. Erstelle ein neues Issue mit:
   - Beschreibung des Problems
   - Schritte zur Reproduktion
   - Erwartetes vs. tatsächliches Verhalten
   - Screenshots (falls relevant)

### Feature Requests

Feature-Wünsche sind willkommen! Erstelle ein Issue mit:
- Beschreibung der gewünschten Funktion
- Anwendungsfall / Nutzen
- Optionale Implementierungsideen

### Pull Requests

1. Fork das Repository (GitHub/Codeberg)
2. Erstelle einen Feature-Branch (`git checkout -b feature/mein-feature`)
3. Folge den Coding Conventions aus [CLAUDE.md](CLAUDE.md)
4. Committe deine Änderungen (`git commit -m 'feat: Add some feature'`)
5. Push den Branch (`git push origin feature/mein-feature`)
6. Erstelle einen Pull Request

**Wichtig:** Bitte stelle sicher, dass:
- Der Code funktioniert und getestet wurde
- Die Dokumentation aktualisiert wurde (falls nötig)
- Der Commit-Message klar ist
